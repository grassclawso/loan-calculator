# Requirement: Loan Repayment Calculator
Provide an interactive form for users to calculate a monthly amortization schedule.

## Inputs
- Loan Amount (Principal)
- Annual Interest Rate (Percentage p.a.)
- Loan Period (Duration in months)

## Core Outputs
- Fixed Monthly Payment amount.
- An amortization table breaking down each month's Payment, Interest portion, Principal portion, and remaining Balance.
